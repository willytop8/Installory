# Installory Full Re-Audit — 2026-07-15

**Scope:** the shipped macOS app (`App/`), `InstalloryCore` Swift package
(`Installory/`), persistence and build infrastructure, tests, and the separate
static website repository (`website/`).

**Method:** six read-only audit passes (core correctness, app lifecycle/UX,
security/privacy, performance, website, and test health), followed by independent
source verification of every accepted High or Critical finding. Platform claims
were checked against current primary documentation rather than copied from the
2026-07-09 audit.

**Baseline:** branch `campaign/2026-07-audit`, starting commit `bada41d`. The core
suite passes with **480 Swift Testing tests in 48 suites plus 21 XCTest cases**.
The app and website repositories were both clean at campaign start. The main app
contains zero `Process(` and zero `URLSession`/network usage in `Installory/Sources`
and `App/Sources`.

Effort: **S** = under an hour, **M** = an afternoon, **L** = a day or more.

## P0/P1 — Source-verified High findings

### CORE25-001 · Failed, timed-out, or malformed scans delete last-known inventory and provenance — **High, M**

**Source:** `Scanners/PackageScanner.swift:21-25`, `CargoScanner.swift:29-33`,
`ScanCoordinator.swift:67-87`, `Persistence/PackageDAO.swift:39-47`, and
`App/Sources/AppCoordinator.swift:731-769`.

**Defect/failure:** the coordinator emits no packages for an unsuccessful manager,
while the app replaces the entire cached inventory with only successful results.
Cargo also turns malformed authoritative metadata into a successful empty result.
A transient grant failure, timeout, or malformed `.crates2.json` therefore removes
the manager's last-known rows and cascades away their provenance evidence.

**Fix:** distinguish genuine empty roots from unreadable/malformed state and merge
successful manager partitions into the previous inventory, preserving partitions
for failed/timed-out/skipped scanners. Homebrew formulae and casks must be treated
as one scanner-owned partition. Regression:
`failedOrTimedOutScannerPreservesLastKnownManagerRowsAndProvenance`.

### CORE25-002 · Targeted Homebrew rescans corrupt manager partitions — **High, S–M**

**Source:** `Scanners/BrewScanner.swift:28-40` and
`App/Sources/AppCoordinator.swift:378-413,837-845`.

**Defect/failure:** `BrewScanner.manager` is `.brew` but it emits both `.brew` and
`.brewCask`. Both targeted-rescan cases instantiate it, and reconciliation uses
the event manager. Rescanning formulae duplicates casks; rescanning casks removes
formulae and appends both categories.

**Fix:** model scanner coverage explicitly or filter returned rows to the requested
partition during targeted reconciliation. Regression:
`homebrewTargetedRescanReplacesOnlyRequestedManager`.

### CORE25-003 / SEC25-003 · Newlines in metadata can inject executable lines into generated scripts — **High, S**

**Source:** `Cleanup/ShellScriptHelpers.swift:3-25`,
`Cleanup/ScriptGenerator.swift:178-220,270-279`, and
`Cleanup/ReinstallScriptGenerator.swift:95-118`.

**Defect/failure:** active shell arguments are safely quoted, but names, versions,
qualifiers, denylist reasons, MAS labels, and cask artifact paths are interpolated
into comments without CR/LF/control-character sanitization. macOS filenames may
contain newlines; a second injected line is no longer commented and executes when
the user runs the generated script.

**Fix:** central `shellCommentText` sanitization applied to every metadata-derived
comment/header fragment in both generators. Regressions must cover hostile
qualifiers, artifact paths, versions, MAS names, and denylist text.

### CORE25-004 · pipx suffixed installs collide and target the wrong environment — **High, M**

**Source:** `Scanners/PipxScanner.swift:47-69,122-143`,
`Cleanup/ScriptGenerator.swift:241-242,294-304`, and
`Cleanup/ReinstallScriptGenerator.swift:136-140`.

**Defect/failure:** pipx supports `--suffix` so multiple copies of one package can
coexist, but the scanner discards the venv/tool directory name and keys packages
only by distribution name. Rows collide and `pipx uninstall <name>` can target a
different environment.

**Fix:** retain exact pipx environment identity separately from display name, use
it in stable IDs and removal/reinstall targeting, and test two suffixed copies.
Primary reference: <https://pipx.pypa.io/stable/reference/cli/>.

### CORE25-005 · pip ignores the installed direct-request marker — **High, S–M**

**Source:** `Foundation/DistInfoParser.swift:3-49,67-83`,
`Scanners/PipScanner.swift:55-75`, and `PipScannerTests.swift:179-187`.

**Defect/failure:** every pip distribution is marked explicit. Current pip writes
the PEP 376 `REQUESTED` extension for user-supplied requirements, so dependencies
without that marker are incorrectly presented as explicit orphan/review candidates.

**Fix:** parse marker presence and use it for explicitness, with a documented
compatibility fallback for metadata produced by tools that do not write it.
Regression: `pipRequestedMarkerControlsExplicitness`. Primary references:
<https://peps.python.org/pep-0376/> and pip's upstream release history.

### CORE25-006 · RubyGems dependency parsing misses generated `%q<...>` syntax — **High, S–M**

**Source:** `Scanners/GemScanner.swift:158-183` and real system gemspecs under
`/Library/Ruby/Gems/.../specifications`.

**Defect/failure:** the parser accepts only single- and double-quoted dependency
names, while installed RubyGems stubs commonly use
`add_runtime_dependency(%q<name>.freeze, ...)`. Required gems then look orphaned
and dependency-aware cleanup ordering loses edges.

**Fix:** parse the bounded `%q` delimiter forms emitted by RubyGems without
evaluating Ruby. Regression: `generatedRubyGemsPercentQDependenciesAreParsed`.

### CORE25-007 · Multiple installed gem versions collapse nondeterministically — **High, M**

**Source:** `Scanners/GemScanner.swift:30-35,80-112` and
`Cleanup/ScriptGenerator.swift:245-250`.

**Defect/failure:** gem IDs exclude version even though RubyGems permits several
versions in one specifications directory. Filesystem order decides which version
survives, and removal does not target the recorded version.

**Fix:** version-bearing gem identity plus `gem uninstall ... -v <version>`.
Regressions: `multipleGemVersionsRemainDistinct` and
`gemRemovalTargetsRecordedVersion`.

### APP25-001 · Failed scan replacement destroys otherwise valid cached state — **High, M**

App-layer manifestation of CORE25-001. Preserve failed scanner partitions in both
memory and persistence, while allowing a successful empty scan to clear its own
partition. Surface the stale partition status in the UI.

### APP25-002 / SEC25-007 · Raw symmetric path-prefix grant matching selects unrelated or overbroad grants — **High, S–M**

**Source:** `App/Sources/FolderAccessManager.swift:121-127` and provenance grant
use in `AppCoordinator.swift:629-636,800-812`.

**Defect/failure:** string `hasPrefix` matching treats `/Users/me2` as related to
`/Users/me` and treats a child grant as covering its parent. Dictionary order may
also select an overbroad grant. Provenance can display/use the wrong grant and
revocation can remove an unrelated bookmark.

**Fix:** standardized, path-component-aware, one-way ancestor coverage; choose the
narrowest valid ancestor and provide precise remove-by-path APIs. Regression tests
belong on extracted path-matching logic.

### APP25-003 · Snapshots and persisted provenance are not hydrated at launch — **High, M**

**Source:** `AppCoordinator.swift:153-178,246-263`, `RootView.swift:80-82`, and
`Persistence/ProvenanceDAO.swift`.

**Defect/failure:** packages and the last scan date load synchronously, but snapshots
load only when exiting demo mode and provenance has no bulk fetch. With scan-on-launch
disabled—or before a scan completes—valid persisted snapshots and provenance appear
missing.

**Fix:** one startup hydration task independent of auto-scan, a provenance bulk-read
API, and visible cache-read failure state.

### APP25-004 / SEC25-009 · Views probe external install paths after security scope ends — **High, M**

**Source:** direct `FileManager.fileExists` calls in
`Views/PackageDetailView.swift:76` and `Views/PackageListView.swift:335`; scan scopes
end in `AppCoordinator.scan()` before later view interactions.

**Defect/failure:** sandboxed existence checks and Reveal affordances can be wrong
for user-granted locations once their bookmark scope has ended.

**Fix:** route external-path inspection/reveal through a component-aware matching
bookmark and a tightly balanced scoped-access helper.

### APP25-005 · Demo mode hides the provenance feature it seeds — **High, S**

**Source:** `AppCoordinator.enterDemoMode()` seeds provenance, while
`SidebarView.swift`, `AIInstalledView.swift`, and `PackageDetailView.swift` gate it
solely on the persisted opt-in toggle.

**Defect/failure:** App Review/demo users cannot see AI provenance unless they had
previously enabled real collection.

**Fix:** use `isDemoMode || provenanceCollection` only as a display gate; retain the
strict collection guard in `scan()`.

### APP25-006 / SEC25-006 · “Clear install history” reports success after database failure — **High, S**

**Source:** `AppCoordinator.clearProvenanceEvidence()` uses `try?` and then clears
memory unconditionally.

**Defect/failure:** sensitive evidence may remain on disk while disappearing from
the UI, misleading the user about deletion.

**Fix:** surface the error and clear in-memory state only after durable deletion.
Regression should use an injected failing DAO/store seam.

### SEC25-001 · Save/export behavior conflicts with the shipped read-only entitlement — **High, decision required**

**Source:** `Installory.entitlements` grants only
`com.apple.security.files.user-selected.read-only`; `AppCoordinator.swift:468-507`
and `Views/ScriptSheetView.swift:93-102` write to `NSSavePanel` destinations.

**Defect/failure:** Apple requires the user-selected read-write entitlement for
writing to a file selected in an Open or Save panel. The shipped entitlement does
not authorize the advertised save/export path.

**Fix choices:** (A) user-approved addition of
`com.apple.security.files.user-selected.read-write`, while preserving read-only
scanning and never mutating scanned resources; or (B) preserve the exact entitlement
and replace arbitrary-location writes with clipboard/container-only export. This
is an invariant decision reserved for the user. Primary references:
<https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.files.user-selected.read-write>
and <https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox>.

### SEC25-002 · Open/save panel security scopes are never relinquished — **High, S**

**Source:** `FolderAccessManager.requestAccess`, `AppCoordinator` export methods,
and `ScriptSheetView.save()` use panel-returned URLs but never call
`stopAccessingSecurityScopedResource()`.

**Defect/failure:** Apple documents that the OS implicitly starts security-scoped
access for open/save-panel URLs “as if” the app called start; callers must stop it
after access. Repeated grants/exports can leak the process's finite sandbox-extension
resources until relaunch.

**Fix:** balance every successful panel URL lifetime with a defer/stop after bookmark
creation or writing. Primary reference:
<https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox>.

### SEC25-004 · Website privacy copy contradicts the shipped provenance feature — **High, M, user copy review**

**Source:** `website/privacy/index.html` versus the 1.3.1 opt-in provenance UI and
collectors.

**Defect/failure:** the policy says the current release does not read shell/AI logs
and describes provenance as future/per-source, while 1.3.1 ships combined opt-in
collection. Users receive inaccurate disclosure.

**Fix:** update disclosure, exact local sources, opt-in/erase/grant behavior, and
export boundaries. Copy must be shown to the user before commit under campaign §8.

### SEC25-005 · Raw provenance secrets are persisted and shown without a central redaction boundary — **High, M**

**Source:** `ClaudeCodeLogCollector`, `ShellHistoryCollector`,
`ProvenanceCollector`, `NarrativeRenderer.swift:58-82`, and the AI-installed view.

**Defect/failure:** shell commands, Claude summaries, paths, and first-message text
are persisted unredacted; at least one UI path bypasses `NarrativeRenderer`.
Secrets typed on command lines or in prompts can reappear in UI/screenshots even
after adding renderer-only masking.

**Fix:** central bounded `ProvenanceRedactor` at ingestion before persistence, plus
defense-in-depth rendering. Tests must cover common token/password/key assignments,
URLs with credentials, and length/path minimization without destroying useful
package evidence.

## Performance findings

- **PERF25-001 — High, M (CORE-07 severity upgraded):** structured timeout
  scopes still wait for non-cooperative scanner children, so nominal deadlines
  are not wall-clock deadlines. Add cancellation checkpoints and realistic
  filesystem-walk tests; do not “fix” this by abandoning unstructured work.
- **PERF25-002 — High, M (CORE25-014):** terminating the scan stream does not
  cancel its detached producer. Add `onTermination`, suppress `allFinished`
  after cancellation, and guard AppCoordinator replacement/persistence.
- **PERF25-003 — High, L (CORE-05):** size collection must be entry/byte/time
  bounded, symlink-safe, and manager-aware or it becomes the dominant scan cost.
- **PERF25-004 — High, M (CORE-11 severity upgraded):** dense timestamp windows
  can create roughly 25 million checks and 24,995,000 persisted co-install IDs
  for 5,000 packages. Sort once, use a sliding window, and persist a bounded
  deterministic sample plus total count.
- **PERF25-005 — Medium-High, M:** provenance collection eagerly loads entire
  histories/JSONL sessions into multiple representations and is not cancellable.
  Add bounded streaming/line parsing and cancellation between records/files.
- **PERF25-006 — Medium-High, S–M:** provenance persistence performs one actor
  hop and write transaction per package. Add atomic `upsertAll(_:)`.
- **PERF25-007 — Medium, M:** database open/migration, package cache load,
  `replaceAll`, and scan-run saves execute synchronously on MainActor. Move
  persistence work behind an async actor/service and publish results back.
- **PERF25-008 — Medium, M:** listing snapshots decodes and retains every full
  historical inventory. List lightweight summaries and lazy-load one payload.
- **PERF25-009 — Medium, M:** SwiftUI repeatedly recomputes manager counts,
  groups, orphans, AI attribution, PATH resolution, and sorting over the whole
  inventory. Add a generation-keyed inventory index and capture derived values
  once per body evaluation.
- **PERF25-010 — Medium, S:** bulk script topological sorting uses
  `removeFirst()` plus repeated queue sorting, creating quadratic churn. Use a
  head index/deterministic priority structure.
- **PERF25-011 — Medium, S–M:** pip/pipx parse full RECORD and INSTALLER files
  that inventory output discards. Provide metadata-only parsing; stream RECORD
  only if used for bounded size accounting.
- **PERF25-012 — Medium-Low, S–M:** export rendering and writes run on MainActor.
  Keep the save panel on-main, then render/write immutable inputs off-main.

## Website findings

**Deployment verification:** direct production downloads on 2026-07-15 proved
that `index.html`, `privacy/index.html`, and `styles.css` are byte-for-byte
identical to local website commit `3f67a45` (matching SHA-256 hashes and byte
counts). Live headers include the configured CSP, HSTS with subdomains/preload,
`X-Frame-Options: DENY`, Permissions Policy, nosniff, and strict-origin referrer
policy. A cached search/browser representation showing the pre-launch homepage
was rejected as stale evidence; **WEB25-001 (“production is undeployed”) is not
an accepted finding**.

Prior WEB-01/02/03, WEB-05/06/07/08/10, and most WEB-11 mechanics are fixed and
deployed. WEB-04 and WEB-F1/F2/F3 remain user-review copy work.

- **WEB25-002 — High, S, user copy review (SEC25-004):** support and privacy
  pages falsely say the current release does not read shell history or AI
  transcripts. Disclose default-off, explicit grant, local persistence,
  revocation, and erase behavior.
- **WEB25-003 — High, S, user copy review:** the Netlify support form collects
  name, email, and message, while the policy broadly says no personal data is
  collected and never scopes that statement to the app. Disclose the website
  form, processor/purpose, retention, and deletion contact.
- **WEB25-004 — High, S, user copy review:** homepage cleanup claims such as
  “undoable” and “any cleanup can be reversed” overstate snapshot/reinstall
  guarantees. Exact versions/sources cannot always be restored. Describe
  snapshots as records and reinstall guidance with manager limitations.
- **WEB25-005 — Medium, S:** the reduced-motion block appears before later,
  more-specific `.shot.tilt:hover` and `.feature:hover` transforms, so it loses
  the cascade. Move it last, match specificity, and disable relevant transitions.
- **WEB25-006 — Medium, S:** asset caching says screenshots refresh within a day,
  but a seven-day `max-age` remains fresh for a week before
  `stale-while-revalidate` applies. Version/hash filenames or shorten max-age.
- **WEB25-007 — Low, S, user copy review:** meta descriptions are poorly sized
  and likely to be rewritten/truncated; draft unique factual snippets.
- **WEB25-008 — Low, S:** website README still documents removed PNG fallbacks
  instead of the deployed three-width WebP `srcset` pipeline.

Local responsive screenshots total about 426 KB across six variants, with only
one width selected per viewport. The prior ~1.1 MB PNG fallbacks and unused
169 KB icon are gone. The official-form Apple badge SVGs, custom 404, semantic
forms/headings, skip links, visible focus treatment, self-hosted fonts, image
dimensions, lazy below-fold image, valid robots/sitemap, and no third-party
runtime assets were positively rechecked.

## Test-health and CI findings

- **TEST25-001 — High, S:** CI compiles/tests only SwiftPM core. It never
  regenerates the gitignored Xcode project or builds the shipped app in Debug
  and Release, so app/resource/XcodeGen failures can merge green. Add a pinned
  XcodeGen app-build job with signing disabled.
- **TEST25-002 — High, S:** defining product invariants have no automated guard.
  Add a dependency-free production-source/entitlement check for subprocesses,
  runtime network, and sandbox/bookmark settings. Finalize the entitlement
  assertion only after the export-entitlement decision.
- **TEST25-003 — Medium, M:** there is no app logic test target and concrete
  globals make AppCoordinator/bookmark/defaults transitions untestable. Add a
  narrow XcodeGen unit target and injectable stores/scanner/scope adapters; do
  not add a UI automation suite.
- **TEST25-004 — Medium, S–M (INF-08):** construct/seed v1, migrate through v2,
  assert row/FK preservation and fresh/upgraded schema equivalence.
- **TEST25-005 — Medium, M:** timeout tests use cooperative `Task.sleep` mocks and
  hide the real cancellation failure. Exercise an instrumented large provider.
- **TEST25-006 — Medium, S–M:** all coordinator tests drain streams completely;
  add abandoned-consumer/cancellation/no-overlap coverage.
- **TEST25-007 — Medium, M:** the in-memory filesystem cannot model readable
  empty directories, injected access failures, varied enumeration, access
  tracing, or cancellation. Extend it before testing scanner failure semantics.
- **TEST25-008 — Medium, M:** the corpus generator can overwrite production with
  `--limit`, skipped registries, or mass fetch failures. Add `--check`/explicit
  partial output, count floors, atomic writes, and stdlib unit tests.
- **TEST25-009 — Low, M:** copied fixtures are accessed via source-tree paths and
  Cargo/pipx/gem/MAS formats are simplified inline examples. Use
  `Bundle.module` and add anonymized real-world smoke fixtures.

Flakiness notes: snapshot ordering sleeps 10 ms instead of injecting `now`, and
timeout tests use real 50 ms deadlines. Replace these when touching the relevant
APIs; they do not justify a new clock dependency.
